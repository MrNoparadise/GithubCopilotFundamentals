# Reference configuration

- `.github/copilot-instructions.md` and `.github/instructions/ui.instructions.md` — the two
  instruction files from the session, the same as on the `with-docs` branch.
  Copy `.github/` into a project as a starting point, then replace the rules with your own.
- `.vscode/mcp.json` — the demo repo's `angular-cli` server plus the Figma remote MCP server.
  See `workshop/handouts/03-figma-mcp.md`.
